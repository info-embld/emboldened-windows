# Emboldened for Windows

The Emboldened desktop App for Windows 10 and 11. Reading, writing, focus and light tools that float over Word, Outlook, PDFs and every other app, and work offline.

## Download

Get the newest version here: [Emboldened-Setup.exe](https://github.com/info-embld/emboldened-windows/releases/latest/download/Emboldened-Setup.exe)

Or see every version on the [Releases](https://github.com/info-embld/emboldened-windows/releases) page.

## Install

1. Download Emboldened-Setup.exe.
2. Double-click it and follow the steps.
3. If Windows shows "Windows protected your PC", click More info, then Run anyway.
4. Emboldened starts on its own. Its toolbar floats on screen and its icon sits in the system tray, by the clock.

Every Pro tool is on for 14 days, no card needed. One Pro licence covers the App and the Chrome extension.

## Uninstall

Open Settings, then Apps, then Installed apps. Find Emboldened, click the three dots and choose Uninstall.

## Privacy

Emboldened works on your computer. We never collect what you read, type or say.
